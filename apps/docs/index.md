features:
  - title: Library and progress
    details: Categories, search, sorting, resume where you left off, history, and moving an anime to another source without losing progress.
  - title: Downloads and offline
    details: A persistent queue for HLS and MP4, a size limit, and offline playback. New-episode checks run on a schedule.
  - title: Sandboxed extensions
    details: Sources are extensions from repositories you add yourself. They run in a sandbox, and repositories are signed with keys you decide to trust.
  - title: Private by design
    details: No telemetry. DNS over HTTPS, a proxy, a custom User-Agent and an incognito mode are built in.

::: warning Beta, unsigned
Releases are beta. The Windows and macOS builds are not code-signed, so your system warns you on first run: [how to get past it](/guide/getting-started#first-run-warnings).
:::

::: info Disclaimer
Matane Anime does not host, store or distribute any content, and ships with no sources, repositories or keys. The developers are not affiliated with anything that third-party extensions provide. See the [FAQ and disclaimer](/faq).
:::
