# Settings

## Where are the settings?

**Settings** in the sidebar. Every option is explained in the [Settings reference](/docs/guides/settings).

## Do I need to press Save?

No. Changes apply and are saved right away. The Network page also has **Test connection** to check settings before you rely on them.

## How do I change the theme or accent colour?

**Settings, General, Appearance**. See [Appearance](/docs/#appearance).

## How do I change the language?

**Settings, General, App language**: English, Bahasa Indonesia or match the system. The **Content language** setting only decides which sources are offered.

## How do I show 18+ sources?

**Settings, General, Show 18+ sources**. It is off by default and hides adult extensions in the repository list, Browse and Global search.

## How do I run the first-time setup again?

**Settings, About, Run setup again**.

## How do I switch to beta versions?

**Settings, About, Update channel**, then choose **Beta**. It applies to the next update check.

## How do I reset everything?

There is no single button. Clear history and watch time in **Settings, Data and storage**; to start from nothing, delete the app's user data folder (and your download folder if you want) after making a [backup](/docs/guides/backups).

## Can I run the app in the background?

**Settings, General, System**: start with your computer and close to the system tray.
