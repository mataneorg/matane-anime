# Source migration

Use migration when a source goes away, breaks for good, or you prefer another source for the same anime. Your progress and history carry over.

## Migrating an anime

1. Right-click the anime in the library and choose **Migrate to another source…** (or use the **Migrate to another source** button on its page).
2. Search the other sources. The dialog lists matches from every other installed source; if you have no other source, install one first ([Extensions and repositories](/docs/guides/extensions)).
3. Pick the right anime. The app fetches its episodes and shows a summary: how many episodes with progress **match by number** and will carry over, and which ones have no match and will lose their progress.
4. Choose **Migrate**.

Your library entry, categories and history move to the new anime. The old one stays out of your library. If you had not watched anything yet, only the library entry moves.

::: tip
Episodes are matched by their number. If the new source numbers episodes differently (for example a season continues from 13 instead of restarting at 1), some progress may not match: the summary tells you before anything changes.
:::

## If the source is simply gone

Anime from an uninstalled extension stay in your library as "not installed" and keep their progress, so you can install the extension again or migrate them. See [FAQ: Extensions](/docs/faq/browse/extensions).
