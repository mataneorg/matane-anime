# Command palette

<Shot name="command-palette" alt="The command palette" />

Press <kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on macOS) anywhere in the app, or use the search button in the title bar. It is not available inside the player.

Type to search; the results are grouped:

- **Continue watching**: the anime you left unfinished, with the episode and the time left. Choose one to resume.
- **Library**: anime in your library, found by title. <kbd>Enter</kbd> opens the anime's page.
- **Go to**: any page of the app (Library, Browse, Updates, Downloads, History, Statistics, Extensions, Settings and so on).
- **Actions**: **Check for updates** (new episodes), **Pause all downloads** or **Resume all downloads**, and **Toggle incognito**, which says whether it is on right now.
- **Sources**: **Search "your text" in all sources** starts a [global search](/docs/guides/getting-started#searching-with-global-search).

Move with <kbd>↑</kbd> and <kbd>↓</kbd>, open with <kbd>Enter</kbd> and close with <kbd>Esc</kbd>. The bottom of the palette shows the keys that work for the selected result.
